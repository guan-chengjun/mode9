# 交互式 3D 液压机可视化演示项目

基于 **Three.js + 原生 JavaScript（ES Modules）+ CSS** 的三维液压机教学演示工程。
模型采用程序化建模（无需下载模型即可运行），同时**支持加载线上 GLB 三维模型**。

---

## 一、功能总览

| # | 功能 | 实现说明 |
|---|------|----------|
| 1 | 360° 自由视角 | OrbitControls：左键拖拽旋转（无俯仰角锁定）、滚轮缩放、右键平移 |
| 2 | 实体 / 透视双模式 | 一键 X-Ray：机架、缸筒、油箱、阀体等外壳半透明 + 蓝色线框，内部活塞、油腔、阀芯、齿轮全部可见 |
| 3 | 真实液压循环动画 | 待机 → 快速下行 → 慢速加压 → 保压 → 泄压 → 活塞回升 六阶段状态机，含启动 / 暂停 / 重置与 0.25×–3× 调速 |
| 4 | 部件点击标注 | 射线拾取 10 个核心部件，弹出跟随 3D 锚点的悬浮信息面板（名称、作用、工作原理） |

可点击的 10 个核心部件：**液压主油缸、活塞（杆）、上压板、下工作台、液压泵（含电机）、液压油箱、三位四通换向阀、溢流阀、油管、机架**。

## 三、运行方式

> ⚠️ 工程使用 ES Modules，**不能直接双击 index.html 用 file:// 打开**（浏览器会因 CORS 拦截模块加载），必须通过 HTTP 服务器访问。

### 方式 1：PowerShell 一键启动（Windows，无需安装任何东西）

```powershell
.\scripts\serve.ps1
```

脚本会在 `http://localhost:8080` 启动静态服务器并自动打开浏览器。
若 8080 端口被占用，可传参：`.\scripts\serve.ps1 -Port 9000`。

> 若首次运行提示「无法加载脚本，因为在此系统上禁止运行脚本」，
> 执行一次 `Set-ExecutionPolicy -Scope Process Bypass -Force` 后再启动即可
> （仅对当前终端窗口生效，不修改系统全局策略）。

### 方式 2：Python（跨平台）

```bash
# Python 3
python -m http.server 8080
# 浏览器访问 http://localhost:8080
```

### 方式 3：Node.js

```bash
npx serve .
# 或
npx http-server -p 8080
```

### 网络要求

Three.js 与 OrbitControls/GLTFLoader 通过 jsDelivr CDN 加载：

```
https://cdn.jsdelivr.net/npm/three@0.160.0/...
```

首次运行需要联网；如需完全离线，可把 `three` 包下载到本地并修改 `index.html` 中的 importmap 路径。

## 四、操作说明

### 视角控制
| 操作 | 效果 |
|------|------|
| 鼠标左键拖拽 | 360° 旋转视角（可从机器底部、顶部任意角度观察） |
| 鼠标滚轮 | 缩放（距离限制 2.2–22） |
| 鼠标右键拖拽 | 平移相机 |
| 触屏 | 单指旋转、双指缩放/平移 |

### 透视模式
点击控制面板 **【透视模式】** 按钮（或再次点击退出）：
- 外壳部件（机架、缸筒、压板、工作台、油箱、泵壳、阀体）变为 10%–18% 透明度并叠加淡蓝线框；
- 内部结构实体显示：活塞头与活塞杆、上下油腔油液、换向阀阀芯、泵齿轮副、油流粒子。

### 液压动画
1. 点击 **【▶ 启动】** 开始循环，**【⏸ 暂停】** 冻结在当前瞬间（油流、阀芯、压力表全部停住），**【↺ 重置】** 回到初始位姿；
2. 拖动 **动画速度** 滑块在 0.25×–3× 之间实时调节；
3. 右侧「实时工况」显示当前阶段名称、系统压力（MPa），阶段序列灯随工序点亮；
4. 观察要点：
   - 快速下行时泵全速、低压大流量；
   - 接触工件后压力指数上升，达到 24 MPa 时**溢流阀阀芯顶开**、溢流管出现脉动油流；
   - 保压时换向阀回中位、电机低速卸荷、上腔封闭压力缓降；
   - 泄压后阀切右位，压力油进入有杆腔，活塞快速回升。

### 部件标注
- 鼠标悬停任意部件：指针变手型、部件橙色高亮；
- 点击：弹出信息面板，内容包含**作用**与**工作原理**两段讲解；
- 面板会跟随该部件的三维锚点移动，旋转视角时自动重定位，点击空白处或 ✕ 关闭；
- 拖拽旋转与点击通过位移阈值区分，正常旋转不会误触发面板。

## 五、技术要点

1. **双材质 X-Ray**：每个外壳网格同时挂载 `MeshStandardMaterial`（实体）与叠加的线框克隆网格，透视时实体降透明度并关闭深度写入，线框显示，内部件不受影响。
2. **液压状态机**（`hydraulic.js`）：六阶段各自定义完整状态向量——阀芯位置、6 条管路的有向流速、系统压力曲线、溢流阀开度、电机转速倍率、两腔压力颜色，阶段间参数平滑插值，无跳变。
3. **真实运动学**：滑块位置驱动活塞组；缸内上/下油腔为独立圆柱网格，按活塞头实时位置改 `scale.y` 与 `position.y`，体积此消彼长；工件按体积近似守恒做塑性压缩形变。
4. **油流可视化**：每条管路用 `CatmullRomCurve3 + TubeGeometry` 建管，9 个粒子沿曲线 `getPointAt` 循环流动，流速/方向/闪烁由当前液压阶段驱动。
5. **拾取稳定性**：线框叠加网格与粒子关闭 raycast，仅注册的部件网格参与检测；OrbitControls 拖拽不触发点击。

## 七、常见问题

**Q：页面空白，控制台报 `Failed to fetch module`？**
A：用了 file:// 直接打开。请按第三节通过本地服务器运行。

**Q：GLB 加载失败？**
A：检查 `config.js` 中的 `glbUrl` 是否可跨域访问（目标服务器需返回 CORS 头），失败后程序会自动回退内置模型，不影响其他功能。详见 `docs/GLB_GUIDE.md`。

**Q：想修改压力、保压时长等参数？**
A：全部集中在 `js/config.js` 的 `PHASES`、`MOTION` 常量中，改数值即可，无需动状态机代码。
